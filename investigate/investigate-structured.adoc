= Untersuchung strukturierter Daten in AI Data Engine
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Wenn der Datenbankspeicher unerwartet wächst, können Sie anhand der Tabellenmetadaten filtern, um festzustellen, welche Tabellen überdimensioniert sind oder seit ihrer ersten Erkennung keine Aktivität mehr aufweisen. So kann beispielsweise ein Speicheradministrator große Tabellen erkennen, die sich seit einem früheren Scan nicht verändert haben, und anschließend mit dem Datenbankeigentümer abstimmen, ob diese noch benötigt werden.

.Bevor Sie beginnen
* Mindestens eine Datenbankdatenquelle muss verbunden sein und gescannt werden. Weitere Informationen finden sich unter link:../data-sources/connect-data-source.html["Herstellen einer Verbindung mit einer Datenquelle"].




[[review-the-database-table-listing]]
== Überprüfen Sie die Auflistung der Datenbanktabellen.

.Schritte
. Wählen Sie in der AI Data Engine Benutzeroberfläche die Option *Investigation* aus.
. Die Registerkarte *Structured* ist auszuwählen.
+
Die Tabelle zeigt den Namen der Datenbanktabelle, das Schema, den DB-Server, den Zeitpunkt der Erkennung, die Tabellendimensionen (Spalten × Zeilen) und die Tabellengröße an.





[[identify-oversized-or-unused-tables]]
== Ermittlung übergroßer oder ungenutzter Tabellen

Mithilfe von Filtern lässt sich die Liste auf Tabellen eingrenzen, die am ehesten Möglichkeiten zur Rückgewinnung bieten.

.Schritte
. Wählen Sie *Filter hinzufügen* und anschließend *Erkennungszeitpunkt* aus.
. Der Bereich wird so festgelegt, dass Tabellen angezeigt werden, die über mehrere Scanzyklen hinweg vorhanden waren, zum Beispiel Tabellen, die vor mehr als einem Jahr erstmals entdeckt wurden.
. Zur weiteren Eingrenzung wird erneut *Filter hinzufügen* ausgewählt und nach DB-Server oder Schema gefiltert, um den Fokus auf ein bestimmtes System zu legen.
+
Angewendete Filter werden als Tags unterhalb der Filterleiste angezeigt. Die Ergebnisse werden aktualisiert, sobald Sie jeden Filter hinzufügen.



Eine vollständige Liste der verfügbaren Filter ist unter link:use-filters.html["Arbeiten mit Filtern"] verfügbar.



[[review-table-details]]
== Details der Übersichtstabelle

Wird eine Tabellenzeile ausgewählt, öffnet sich das Detailfenster, und es lässt sich beurteilen, ob die Tabelle ein Kandidat für die Rückgewinnung ist.

Im Detailbereich werden der Datenbankserver, das Schema, die Tabellendimensionen, die Tabellengröße und der Zeitpunkt der Erkennung angezeigt. Anhand dieser Informationen lässt sich feststellen, ob die Tabelle seit der Erkennung gewachsen ist oder unverändert geblieben ist.


NOTE: Bevor Sie Maßnahmen an Datenbanktabellen ergreifen, stimmen Sie sich mit dem Datenbankeigentümer ab, um zu bestätigen, dass die Tabelle nicht mehr benötigt wird.



[[save-findings-as-a-policy]]
== Ergebnisse als Richtlinie speichern

Nachdem Filter angewendet wurden, die relevante Tabellen identifizieren, werden die Kriterien zur fortlaufenden Überwachung gespeichert.

.Schritte
. In der Filter-Symbolleiste ist die Option *Richtlinie erstellen* auszuwählen.
. Das Richtlinienformular ist auszufüllen. Verweis auf link:../policies/create-policy.html["Erstellung einer Richtlinie"].


Um die gefilterten Ergebnisse von der Registerkarte „Strukturiert“ herunterzuladen, wählen Sie image:icon_download_file.png["Download"] aus.
