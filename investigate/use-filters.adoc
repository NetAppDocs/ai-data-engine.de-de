= Metadatenfilter in AI Data Engine
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die AI Data Engine Untersuchungsansicht bietet Metadatenfilter, um Ihre Ergebnisse auf eine bestimmte Datengruppierung einzugrenzen. Es können gleichzeitig ein oder mehrere Filter angewendet werden, um die Dateien zu definieren, die Sie untersuchen oder bearbeiten möchten.



[[time-filters]]
== Zeitfilter

[cols="1,2"]
|===
| Filter | Beschreibung 


| Zuletzt erstellt | Dateien nach dem Erstellungsdatum filtern. 


| Zuletzt geändert | Dateien nach dem Datum filtern, an dem sie zuletzt geändert wurden. 


| Zuletzt aufgerufen | Dateien nach dem Datum des letzten Zugriffs filtern. Mit diesem Filter lassen sich kalte oder veraltete Daten identifizieren. 


| Zeit der Erkennung | Filtern von Dateien danach, wann AI Data Engine sie während des Scans zum ersten Mal erkannt hat. 
|===


[[file-attribute-filters]]
== Filter für Dateiattribute

[cols="1,2"]
|===
| Filter | Beschreibung 


| Dateityp | Filtern nach Dateierweiterung oder Dateitypklassifizierung. Auswählen eines oder mehrerer Dateitypen aus der Liste. 


| Dateigröße | Nach Dateigröße filtern. Die Eingabe eines Minimalwerts, eines Maximalwerts oder eines Bereichs ist möglich. 


| Datei-/Verzeichnispfad | Es ist möglich, nach dem vollständigen oder teilweisen Pfad der Datei oder des Verzeichnisses, das sie enthält, zu filtern. 


| Datei-/Verzeichnisbesitzer | Filterung nach dem Benutzer oder der Gruppe, dem bzw. der die Datei oder das Verzeichnis gehört. 


| Datei-Hash | Die Filterung nach dem Hashwert einer Datei ermöglicht das Auffinden bestimmter Dateien oder die Bestätigung doppelter Inhalte. 


| Duplikate | Filter, um nur Dateien anzuzeigen, für die im Katalog doppelte Kopien erkannt wurden. 


| Verzeichnistyp | Filtern nach Verzeichnistyp. Gilt für die Registerkarte „Verzeichnisse“. 
|===


[[source-filters]]
== Quellenfilter

[cols="1,2"]
|===
| Filter | Beschreibung 


| Datencontainer | Filter auf ein bestimmtes Volume oder eine bestimmte Freigabe. 


| System | Es ist eine Filterung nach einem bestimmten Cluster möglich. 


| Systemtyp | Nach dem Typ des Speichersystems kann gefiltert werden. 
|===


[[governance-filters]]
== Governance Filter

[cols="1,2"]
|===
| Filter | Beschreibung 


| Tags | Dateien filtern, denen ein bestimmtes Business-Tag zugewiesen wurde. 


| Richtlinie | Dateien, die einer bestimmten gespeicherten Richtlinie entsprechen, werden gefiltert. Richtliniennamen werden in der Filterliste angezeigt. 
|===


[[access-filters]]
== Zugriffsfilter

[cols="1,2"]
|===
| Filter | Beschreibung 


| Anzahl der Benutzer mit Zugriff | Dateien danach filtern, wie viele Benutzer oder Gruppen Zugriff haben. Damit lassen sich allgemein zugängliche Daten identifizieren. 


| Benutzer-/Gruppenberechtigung | Dateien nach einem bestimmten Benutzer oder einer Gruppe filtern, die über Zugriffsberechtigungen verfügt. 
|===


[[combining-filters]]
== Kombinieren von Filtern

Filter werden mit UND-Logik kombiniert, das heißt, die Ergebnisse müssen gleichzeitig allen angewendeten Filtern entsprechen.
