= Schnellstart für AI Data Engine
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AI Data Engine (AIDE) lässt sich durch das Einsetzen des Service, das Verbinden Ihrer Datenquellen und den Start Ihrer ersten Untersuchung in Betrieb nehmen. Auch die Durchsuchung Ihrer Metadaten durch AI Clients über einen kontrollierten AI-Zugriff ist möglich.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Eins"] link:../deploy/aide-requirements.html["Prüfung der Anforderungen und Auswahl eines Deployment Typs"]
[role="quick-margin-para"]
Anhand der Anforderungen und link:../deploy/deployment-overview.html["Informationen zu Deployment-Typen"] lässt sich entscheiden, ob ein AIDE Single-Node oder Multi-Node Deployment installiert werden soll.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Zwei"] link:../deploy/deployment-overview.html["AI Data Engine einsetzen"]
[role="quick-margin-para"]
Die Bereitstellung einer Anwendung link:../deploy/deploy-aide-single-node.html["AIDE Einzelknoten-Deployment"] oder eines link:../deploy/deploy-aide-multi-node.html["AIDE Multi-Node Deployment"] Clusters erfolgt über NetApp Console. Die Einrichtungsseite führt Sie durch die Auswahl des Installationsorts und der Konfigurationsgröße sowie durch die Ausführung des Installationsbefehls. Falls Ihr Host oder Cluster nur über einen Proxy auf das Internet zugreift, wird stattdessen link:../deploy/configure-proxy.html["mit einem Proxy einsetzen"] verwendet.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Drei"] link:../data-sources/connect-data-source.html["Herstellen einer Verbindung mit einer Datenquelle"]
[role="quick-margin-para"]
Zum Starten des Scans ist eine Verbindung mit einer Datenquelle erforderlich. AI Data Engine katalogisiert die Metadaten der Datenquellen, die Sie verbinden.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Vier"] link:../investigate/understand-dashboard.html["Datenexploration"]
[role="quick-margin-para"]
Im Dashboard werden Einblicke in die Storage-Optimierung angezeigt, oder unter link:../investigate/investigate-data.html["Untersuchung"] können Sie Ihre Metadaten direkt durchsuchen und filtern.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Fünf"] link:../policies/create-policy.html["Erstellung einer Richtlinie"]
[role="quick-margin-para"]
Ihre Untersuchungsfilter können als Richtlinie gespeichert werden, um Dateien, die denselben Kriterien entsprechen, im Zeitverlauf zu überwachen. Sie können eine Richtlinie so konfigurieren, dass sie eine Benachrichtigung sendet, übereinstimmende Dateien endgültig löscht oder die Ergebnisse nachverfolgt.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["Sechs"] link:../mcp/quick-start-mcp.html["Optional: Einrichten des kontrollierten KI-Zugriffs"]
[role="quick-margin-para"]
KI-Clients können die Metadaten in den von Ihnen ausgewählten Sammlungen durchsuchen. Fortgeschrittene Benutzer können Metadaten durchsuchen und Aktionen mit den Daten durchführen.
